# Day 1 · Tensor 核心操作

- **本质与用途**：Tensor 是用于数值计算的多维数组，支持批量运算、CPU/GPU 与自动求导。0维是标量，1维是向量，2维是矩阵；`[B,T,C]` 是3维，轴的业务含义由数据约定。
- **属性**：`ndim` 是轴数，`shape` 是各轴长度；`dtype` 是类型，`device` 是设备，`numel()` 是元素总数（各轴长度相乘）。前四个是属性，只有 `numel()` 加括号。
- **创建**：`tensor(data)` 从数据创建；`zeros/ones` 全0/1；`full((2,3),7)` 用元组指定形状并填7；`rand` 均匀分布 `[0,1)`；`randn` 标准正态分布；`arange(start,end)` 左闭右开；`eye(n)` 单位矩阵。创建函数的尺寸参数决定 Shape。
- **索引/切片**：索引从0开始，`-1` 是最后一项；`x[i,j]` 取行列，`start:end` 含头不含尾，`:` 全取。`x[:,0]` 取第一列并去掉该轴，`x[:2,:2]` 取左上2×2；`logits[:,-1,:]` 取所有样本最后位置的预测。`x[0]=...`、切片赋值会修改原张量。
- **广播**：从右向左对齐，缺轴在左补1；每轴须相等或一方为1，否则报错。`[3,4]+[4]→[3,4]`，`[3,1]+[1,4]→[3,4]`，`[2,3]+[2,4]` 不可广播。它是逻辑扩展，无须手动循环或复制整份数据；`scores + bonus` 按列加分。
- **运算**：`+ - * /` 逐元素计算，可广播；`*` 不是矩阵乘法。`@` 与 `torch.matmul`：二维 `[m,k]@[k,n]→[m,n]`，内维须相等，结果按行列点积求和。高维对最后两轴做矩阵乘法，前面批次轴广播；Attention 的 `[B,H,T,D]@[B,H,D,T]→[B,H,T,T]`，`K.transpose(-2,-1)` 交换最后两轴。
- **类型**：整数数据默认通常为 `int64`（Token ID/索引），浮点默认通常为 `float32`（参数/特征）；`float16/bfloat16` 节省存储但精度特性不同；`bool` 用于条件/Mask。类型影响运算兼容性、显存和数值稳定性。
- **转换陷阱**：`.int()/.float()/.double()/.bool()` 分别返回 int32/float32/float64/bool 结果，不会原地改变类型；需要 `a = a.float()` 或 `a = a.to(torch.float32)`。原练习末尾没有接收返回值，因此 `a` 仍为原类型；转 bool 时0为 False，非0为 True。
