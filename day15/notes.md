# Day 15 · Learning Rate

学习率控制优化器更新的整体尺度，需要结合优化器、Batch Size、模型、数据和训练预算选择。

| 学习率表现 | 常见训练现象 |
|---|---|
| 偏小 | Loss 下降慢，相同预算内学习不足 |
| 合适 | Loss 总体下降，收敛速度与稳定性较好 |
| 偏大 | 震荡、发散，严重时出现 NaN |

SGD 中 w=5、g=2，lr=0.001 时变为4.998，lr=0.1 时变为4.8。AdamW 同样用 lr 缩放更新，但方向与逐参数尺度来自梯度历史。

## 怎样比较

固定模型初始参数、数据、批次顺序、训练轮数，只改变学习率。记录整条 Loss 曲线，检查收敛速度、波动及最终表现。正式选择超参数应参考验证表现。

```python
learning_rates = [0.0001, 0.001, 0.01, 0.1]
```

固定学习率在整个训练期间保持不变。学习率敏感性描述改变 lr 后，模型训练速度和效果变化的程度。

| 场景 | 原窗口提供的参考量级 |
|---|---|
| AdamW 从头训练 Transformer | 1e-4 至 1e-3 |
| 大模型全参数 SFT | 1e-6 至 1e-5 |
| LoRA | 1e-5 至 1e-4 |

这些量级仅用于建立直觉，实际数值由实验确定。训练中也可通过 Warmup 与 Decay 随进度改变学习率，见 Day16。
